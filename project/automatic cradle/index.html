Automatic Baby Cradle Prototype

Infant-care automation prototype combining cry acoustic sensing, moisture detection, and motor-driven swinging.

Project Media

Project Overview

The Automatic Baby Cradle is an embedded systems prototype designed to explore how sensors and automated control mechanisms can support basic infant-care tasks through sound detection, moisture sensing, and motor control.

Technologies & Components:

  • Embedded C/C++
  • Sound Sensor & Moisture Sensor
  • Microcontroller & Motor Driver Circuit
