AI-Based Personal Protective Equipment (PPE) Detection System

Automated workplace safety monitoring through computer vision on edge hardware.

Project Media & Demonstration

Project Overview

Workplace safety is a critical concern in industrial environments, where failure to use appropriate Personal Protective Equipment (PPE) can expose workers to serious hazards. As part of a university team at Rajshahi University of Engineering & Technology (RUET), I contributed to the development of an AI-based PPE detection system designed to support automated workplace safety monitoring through computer vision.

Technologies & Tools:

  • Python & OpenCV
  • YOLO-based Object Detection
  • Deep Learning
  • Raspberry Pi & Embedded Systems
