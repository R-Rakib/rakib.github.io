Advanced Machining Knowledge Assistant — RAG-Based System

RAG assistant leveraging LangChain and FAISS vector indices over technical machining textbooks.

Project Demonstration

Project Overview

This project explores a Retrieval-Augmented Generation (RAG) approach to build an interactive knowledge assistant for advanced machining based on V. K. Jain's textbook, utilizing LangChain, FAISS, and Google Gemini 2.0 Flash.

Technologies & Tools:

  • Python, LangChain & FAISS
  • Google Gemini 2.0 Flash
  • Streamlit
